# Photo-create

两套基于上传照片进行“二次创作”的 Codex 技能。两者都会分析主体、光线氛围、空间关系与色彩结构，也都强调保留人物身份、人数、姿态、物件与关系；区别在于最终版式和色彩控制方式。

## 选择哪一个？

| 想实现的效果 | 使用技能 | 关键结果 |
| --- | --- | --- |
| 一张连续的摄影 + 纸张 / 插画 / 抽象图形作品；不固定为海报，不强制上下分区，不希望整体改变原图色调 | [`photo-scene-reconstruction`](./photo-scene-reconstruction/SKILL.md) | 在原照片内部局部“长出”设计语言，适合人物、建筑、动作、旅行瞬间和纪实照片 |
| 3:5 竖版旅行杂志海报；上方摄影、中间交叠过渡、下方派生设计；允许根据情绪进行受控调色 | [`photo-interactive-design`](./photo-interactive-design/SKILL.md) | 具有纸张边框、清晰的双向过渡和视觉平衡的成品海报 |

## 一句话判断

- 想让“设计进入照片本身”，同时照片仍是主角：用 **照片画面重构**。
- 想让“照片成为杂志海报的一部分”，并需要完整的竖版编排：用 **照片交互设计**。

## 安装

将所需技能目录安装到 Codex 的 skills 目录。每一个技能目录都包含独立的 `SKILL.md`：

```text
photo-scene-reconstruction/
photo-interactive-design/
```

安装后在对话中直接点名使用，例如：

```text
[$photo-scene-reconstruction] 请把这张旅行照重构为一张连续的摄影与图形作品。
```

```text
[$photo-interactive-design] 请把这张旅行照制作成 3:5 竖版旅行杂志海报。
```

## 使用方法

### 1. 照片画面重构

适用于任何画幅。它会先划分“真实摄影保留区”和“转化区”，再让纸张、拼贴、线稿、半调或抽象图形从真实边缘、手势、视线、阴影、道路、波纹或物件中生长出来。

推荐说法：

```text
[$photo-scene-reconstruction]
保留人物身份、衣服、姿势和相互关系；保留原图色调与光线。
将右侧空白天空转化为局部冷白纸张，并让海面波纹延续为蓝色半调航线；不要做上下分屏或全局泛黄。
```

适合的场景：

- 人物肖像、多人关系、动作瞬间
- 建筑、街道、桥梁、机翼、海面、山体
- 希望原始光线和调色保持主导的照片
- 想局部加入纸张、印刷、图解、手绘或拼贴，但不想要“海报模板”

### 2. 照片交互设计

固定以 3:5 竖版旅拍海报为核心。上部约 43%-48% 是真实摄影，下部约 32%-38% 是从照片派生的设计；两者通过 10%-15% 的双向过渡区相连。技能会检查上下视觉重量，并可选择忠实自然、统一编辑或情绪化调色。

推荐说法：

```text
[$photo-interactive-design]
以 3:5 竖版旅行杂志海报生成。保留人物和地点；用海岸线作为撕纸过渡，照片中的波纹向下变成半调等高线，设计线条向上进入真实海面。
色彩使用 harmonized editorial：保持肤色和白色干净，把蓝色压成统一的海报主色。
```

适合的场景：

- 需要统一尺寸的旅行海报、Zine 内页或社媒竖图
- 想明确得到“上方照片 + 下方设计”，但两者不能硬切分
- 需要根据情绪强化色彩，例如宁静、怀旧、活力、孤独或出发感
- 同时上传多张照片，并希望每张生成同系列但独立的海报

## 色彩差异

- **照片画面重构**：默认以原图白平衡、曝光、对比和饱和度为基线；纸张和印刷纹理只作用于新增区域或过渡边缘。
- **照片交互设计**：会先选择 `faithful natural`、`harmonized editorial` 或 `expressive mood-led` 之一；可以调色，但必须保护肤色、关键物件色、干净中性色和可识别地点关系。

## 人物照片的共同规则

两套技能都要求：

- 保留可识别人物的脸、身份、体态、衣物、姿势、数量与相对位置；
- 两人或多人时，保留看向、同行、拉扯、共享物件或共同动作等关系；
- 不合并、不新增、不删除、不复制人物，也不把真实人物重画成第二个写实人像；
- 图形必须从人物的手势、衣缘、阴影、持物或人物之间的空隙中获得连接点。

## 常见错误与修正

| 如果成图出现的问题 | 下次补充的要求 |
| --- | --- |
| 只是原图叠几条线 | “必须将一块非关键背景变为可见纸张 / 拼贴 / 半调区域，并与真实边缘精确衔接” |
| 做成了照片和插画两块板 | “不要直线分隔；要求照片向设计区延伸、设计向照片回伸，并共享一条连续轮廓” |
| 原图被整体泛黄或复古化 | “原图的白平衡和曝光必须主导；纸张纹理只限新加入的区域” |
| 下方设计太小，画面头重脚轻 | 对交互设计补充：“下方主锚点至少覆盖可用宽度的 55%，过渡和下方承担 35%-45% 的视觉重量” |
| 人物变脸、人数或动作关系漂移 | “人物为高保真保护对象；不得改脸、增删人、复制人物或改变相对位置” |
